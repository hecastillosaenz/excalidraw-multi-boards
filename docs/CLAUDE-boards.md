   # Contexto del proyecto
   Fork de Excalidraw para uso personal local. Objetivo: multi-tableros con
   persistencia en archivos de disco. Documento de diseño obligatorio:
   docs/SDD-multi-boards.md — léelo completo antes de actuar y respeta su
   acuerdo de trabajo (sección 0) y el presupuesto de archivos (sección 8).
   Proyecto nuevo, sin datos previos: no hay migración (F11 fuera de alcance).
   Idioma de trabajo: español. Código en inglés.
   Carpeta de datos del usuario: ../data respecto a la raíz del repo, es decir
   ~/Projects/excalidraw/data (fuera del repo; configurable con BOARDS_DIR;
   NO borrar nada ahí; debe estar fuera de git).
